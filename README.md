# 💳 ATM Simulation System

## 📌 Project Introduction
The ATM Simulation System is a Java-based application
that simulates basic ATM banking operations.

## 🎯 Objectives
- Simulate ATM operations.
- Provide a simple banking interface.
- Perform basic transactions.
- Understand Java programming concepts.

## ✨ Features
- ATM transaction simulation
- User-friendly console interface
- Basic banking operations

## 🛠️ Technologies Used
- Java
- Visual Studio Code
- Git
- GitHub

## ▶️ How to Run

1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Compile the Java program:

   javac ATMSystem.java

5. Run the program:

   java ATMSystem
